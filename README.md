# Radosti Nails — демонстрационный сайт

Одностраничный адаптивный сайт без сервера и админки. Главная точка: Королёв, проспект Космонавтов, 34Б (ТЦ «Юпитер»). Публичная онлайн-запись: https://n2310255.yclients.com/.

## Как запустить

Откройте `index.html` в браузере или опубликуйте содержимое каталога на любом статическом хостинге (например, GitHub Pages).

## Данные и изображения

Основа: публичная карточка филиала на Яндекс Картах, Taplink Radosti Nails и публичная онлайн-запись YCLIENTS. Прайс носит справочный характер; цены зависят от мастера и могут меняться.

На главном экране используется тематическое фото из Unsplash; фотографии в блоках «Место для себя» и «Моменты» загружаются из открытой фотогалереи карточки организации на Яндекс Картах. Если фотография недоступна, отображается локальная SVG-иллюстрация. Для коммерческой публикации рекомендуется получить оригинальные фото и согласие владельца на их использование.

Все пиктограммы сделаны SVG. Нет базы данных, хранения персональных данных, самостоятельно реализованной записи или админ-панели. Кнопки записи открывают официальный YCLIENTS филиала.
